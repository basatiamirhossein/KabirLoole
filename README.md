# وب‌سایت کبیر لوله (نسخه ۲)

سایت سه‌زبانه‌ی کبیر لوله (فارسی و عربی راست‌چین، انگلیسی چپ‌چین) با ماشین‌حساب وزن و قیمت لوله و یک پنل ادمین کوچک برای قیمت روزانه‌ی هر کیلو.

## دیدن سایت

- **روی همین کامپیوتر:** فایل `index.html` را با مرورگر باز کنید. همه‌چیز کار می‌کند جز قیمت روز، چون پنل و API به PHP نیاز دارند. برای دیدن کامل، در همین پوشه `php -S localhost:8000` را اجرا کنید و `http://localhost:8000` را باز کنید.
- **روی هاست:** کل پوشه را روی یک هاست با **PHP 8.1 یا بالاتر** بگذارید (cPanel معمولی کافی است). دیتابیس لازم نیست.

## ساختار پوشه‌ها

```
index.html, 404.html      صفحه‌ی انتخاب زبان و صفحه‌ی «پیدا نشد»
fa/ ar/ en/               هفت صفحه برای هر زبان، به‌علاوه‌ی صفحه‌ی مقاله‌ها در fa/ (خروجی build؛ دستی ویرایش نکنید)
assets/css, js            خروجی build از src/ (دستی ویرایش نکنید)
assets/fonts/             دانا، KL Latin (رقم‌های لاتین)، وزیر و ساحل
assets/img/               عکس‌ها به فرمت webp
src/css/main.css          کل طراحی
src/ts/                   تعامل‌ها با TypeScript سخت‌گیر (strict)
content/blog/             مقاله‌ها به‌صورت فایل Markdown
build/                    سازنده‌ی صفحات با پایتون و متن سه زبان
api/price.php             API قیمت روز (JSON)
admin/                    پنل ادمین قیمت روزانه
server/                   کد، تنظیمات و داده‌های پنل؛ از وب قابل دسترسی نیست
```

## پنل قیمت روزانه

1. **تعیین رمز (یک بار):** در ترمینال سرور، یا روی کامپیوتر خودتان پیش از آپلود، اجرا کنید:
   ```bash
   php server/set-password.php
   ```
   رمز حداقل ۱۰ حرف است و فقط به‌صورت هش در `server/storage/admin-password.php` ذخیره می‌شود.
2. **ورود:** به `https://دامنه/admin/` بروید، وارد شوید و قیمت هر کیلو مواد اولیه‌ی PE100 و PE80 را به ریال ثبت کنید. می‌توانید با رقم فارسی و جداکننده هم بنویسید.
3. ماشین‌حساب صفحه‌ی محصولات از همان لحظه قیمت هر متر و قیمت کل را با نرخ جدید حساب می‌کند. ده تغییر آخر هم در پنل دیده می‌شود.

امنیت: پنل ورود را بعد از ۵ تلاش ناموفق برای ۱۵ دقیقه می‌بندد، بعد از ۳۰ دقیقه بی‌کاری خارج می‌شود، کوکی آن HttpOnly و SameSite=Strict است و همه‌ی فرم‌ها توکن CSRF دارند. این تنظیمات در `server/config.php` است.

نکته‌های هاست:
- پوشه‌ی `server/storage` باید برای PHP قابل نوشتن باشد.
- روی Apache فایل `server/.htaccess` دسترسی مستقیم به `server/` را می‌بندد. روی Nginx این را اضافه کنید: `location ^~ /server/ { deny all; }`
- سایت را با HTTPS اجرا کنید تا کوکی پنل فقط روی HTTPS فرستاده شود.

**API:** `GET api/price.php` این را برمی‌گرداند (قیمت‌ها ریال بر کیلوگرم؛ `null` یعنی هنوز ثبت نشده):
```json
{"updatedAt": "2026-10-09T10:30:00+03:30", "prices": {"pe100": 1850000, "pe80": 1700000}}
```

## ماشین‌حساب و جدول‌ها

داده‌ی ضخامت و وزن از برگه‌ی مشخصات فنی خود کارخانه (PE80 و PE100، استاندارد ملی ۱۴۴۲۷-۲) در `build/spec.py` است. فرمول:

```
قیمت هر متر = وزن هر متر (کیلوگرم) × قیمت روز هر کیلو
قیمت کل     = قیمت هر متر × متراژ
```

## مقالات (بلاگ)

هر مقاله یک فایل `.md` در `content/blog/` است. صفحه‌ی «مقالات» (`blog.html`) فهرست همه را نشان می‌دهد و هر مقاله صفحه‌ی خودش را دارد (`fa/blog-<slug>.html`). سه مقاله‌ی آخر در صفحه‌ی اول سایت فارسی هم دیده می‌شوند. مقاله‌ها فارسی‌اند؛ صفحه‌ی مقالات عربی و انگلیسی همین مقاله‌ها را با یادداشت «فقط فارسی» نشان می‌دهد.

**افزودن مقاله‌ی جدید:** یک فایل `.md` با این سربرگ در `content/blog/` بگذارید و `python3 build/build.py` را اجرا کنید:

```
---
title: "عنوان مقاله"
slug: english-words-with-hyphens
description: "یک یا دو جمله برای کارت و گوگل"
keywords: ["کلمه ۱", "کلمه ۲"]
category: "آبیاری و کشاورزی"
author: "تیم محتوای کبیر لوله"
date: 2026-10-09
reading_time: "۱۰ دقیقه"
icon: drop
---
```

`slug` آدرس صفحه می‌شود و فقط حروف کوچک انگلیسی، عدد و خط تیره می‌پذیرد. `icon` یکی از نام‌های `build/icons.py` است (مثل drop، sprout، sun، ruler). تاریخ به شمسی نمایش داده می‌شود. متن می‌تواند تیتر، فهرست، جدول، نقل‌قول، پیوند و بولد داشته باشد؛ فهرستی از پیوندهای داخلی بعد از یک تیتر، خودکار به کادر «فهرست مطالب» تبدیل می‌شود.

## ویرایش متن‌ها و ساخت دوباره

متن هر زبان در `build/content_fa.py`، `build/content_ar.py` و `build/content_en.py` است و هر سه باید کلیدها و طول فهرست‌های یکسان داشته باشند؛ وگرنه سازنده خطا می‌دهد. تلفن‌ها، ایمیل و فونت‌ها در `build/data.py` و جدول لوله در `build/spec.py` است. بعد از هر تغییر (از جمله افزودن مقاله):

```bash
python3 build/build.py
```

این دستور صفحه‌ها، CSS فشرده و فونت‌های حالت آفلاین را می‌سازد و اگر `tsc` (TypeScript) نصب باشد، JS را هم کامپایل می‌کند. هیچ پکیج npm لازم نیست.

## فونت‌ها

- **فارسی و انگلیسی:** دانا (FaNum، وزن Regular). تیترها با بولد مرورگر ضخیم می‌شوند. اگر وزن‌های Medium/Bold/Black دانا را دارید، فایل woff2 را در `assets/fonts` بگذارید، در `FONT_FACES` در `build/data.py` اضافه کنید و دوباره بسازید.
- دانا رقم‌های لاتین را فارسی می‌کشد، پس رقم‌های لاتین (مثل PE100 و ISO 9001) و چند علامت از زیرفونت ۴ کیلوبایتی `KL-Latin.woff2` (برگرفته از وزیر) می‌آیند. ساخت دوباره‌ی آن: `python3 build/make_latin_subset.py`.
- **عربی:** وزیر و ساحل، چون دانا «ي» عربی آخر کلمه را بی‌نقطه و اعداد عربی را به شکل فارسی نشان می‌دهد. با تغییر `TYPEFACES["ar"]` در `build/data.py` عوض می‌شود.
- استفاده‌ی وب از دانا به مجوز fontiran.com نیاز دارد.

## قبل از انتشار

- در `build/data.py` مقدار `SITE_URL` را دامنه بگذارید (مثلاً `https://kabirloole.ir`) و دوباره بسازید تا canonical، hreflang، `sitemap.xml` و `robots.txt` ساخته شوند.
- بعد از هر انتشار، `ASSET_VERSION` در `build/data.py` را یک شماره بالا ببرید تا مرورگرها CSS و JS تازه را بگیرند.
- فرم تماس پیام را در برنامه‌ی ایمیل بازدیدکننده آماده می‌کند تا به `KLS_Basati@yahoo.com` برود.
